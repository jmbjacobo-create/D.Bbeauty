# D.B.Beauty

Web estática de servicios y precios. Funciona abriendo `index.html`, sin instalación ni compilación.

Dirección pública: https://jmbjacobo-create.github.io/D.Bbeauty/

## Actualizar La Web

El ZIP contiene `index.html`, `styles.css`, `script.js`, este documento y la carpeta `assets`. Para actualizar GitHub Pages, subir el contenido descomprimido a la misma ubicación del repositorio, conservando la estructura de carpetas. Subir solo el ZIP no actualiza la página.

Si se mantienen el repositorio, el dominio y la ruta de publicación, la dirección pública sigue siendo la misma.
